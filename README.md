# crakpot
Repository for Cosmic Development San Diego's private game engine, Crakpot.



Community: A public, lightweight version for modders and experimenters.

Page: A light two-dimensional game engine.

Block: A optimized engine for simpler block or voxel games.

Design: Our top-of-the-line premier engine for AAA-style games.

Envision: A testing ground to make sure technologies work before being added to Design.
